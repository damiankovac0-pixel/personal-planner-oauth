# Personal Planner

Personal Planner is a private, locally run assistant integration for the account owner’s Google Tasks and native macOS calendars and reminders. It is not a public service.

The Google connector requests task read/write access and basic account identity. It can list, create, update, complete, move, and delete tasks when the owner asks. Native calendar access is separately authorized in macOS.

This site contains app information only. No calendar events, tasks, Google credentials, or access tokens are published here.
